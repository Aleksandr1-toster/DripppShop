# DrippShop — магазин вещей (Node.js + SQLite + ЮKassa)

## Как это устроено
- Регистрация по почте с подтверждением по ссылке из письма, пароли в хешах (bcrypt).
- Админ — тот, чья почта указана в `ADMIN_EMAIL` (проверяется на сервере). Только админ может добавлять и удалять товары.
- Покупатель: лента, поиск, корзина, баланс, покупка, кнопка «Написать админу» (t.me/gunnar_87).
- Баланс пополняется через ЮKassa, покупка списывает деньги с баланса.

## Запуск на своём компьютере (проверка)
    npm install
    JWT_SECRET=test ADMIN_EMAIL=you@mail.ru npm start
Откройте http://localhost:3000. Без настроек SMTP ссылка подтверждения почты печатается в консоль сервера.

## Выкладка в сеть (Railway — пример)
1. Загрузите папку в репозиторий GitHub (папки `node_modules`, `data` и файл `.env` не заливать — они в .gitignore).
2. На railway.app: New Project → Deploy from GitHub → выберите репозиторий.
3. Вкладка Variables: добавьте все переменные из `.env.example`.
4. Добавьте Volume (постоянный диск), путь `/data`. Без него база и фото товаров пропадут при перезапуске.
5. Settings → Networking → Generate Domain (или подключите свой домен). Адрес впишите в `BASE_URL` (https!) и перезапустите.
Подойдёт и Render (платный план с Disk) или любой VPS: `npm install && npm start` под pm2 + nginx с HTTPS.

## Подключение ЮKassa
1. В личном кабинете ЮKassa возьмите shopId и секретный ключ (Настройки → Ключи API) → `YK_SHOP_ID`, `YK_SECRET`. Сначала можно использовать тестовый магазин.
2. Настройки → HTTP-уведомления: адрес `https://ВАШ-ДОМЕН/api/yookassa/webhook`, событие `payment.succeeded`.
3. Протестируйте тестовой картой из документации ЮKassa, потом переключитесь на боевые ключи.
Важно: ЮKassa подключается для юрлица, ИП или самозанятого. Для приёма платежей за товары нужен также чек по 54-ФЗ — настраивается в кабинете ЮKassa.
